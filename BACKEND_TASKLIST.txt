MÖVCUD VƏZİYYƏT
----------------
- Storefront-da yalnız aktiv sliderlər DB-dən oxunur; məhsul, kateqoriya,
  səbət, wishlist, checkout və sifarişlər dinamik deyil.
- Admin paneldə slider create/delete işləyir, lakin məhsul və kateqoriya
  formaları action="#" olduğuna görə məlumat saxlamır.
- Müştəri və admin iki ayrı cədvəldədir (`signup`, `admin_user`); README-də
  nəzərdə tutulan vahid `users` + `role` modeli ilə uyğunsuzluq var.
- `products` migration-da `category_id` səhvən AUTO_INCREMENT PRIMARY KEY-dir;
  məhsulun ayrıca id-si və düzgün əlaqəsi yoxdur.
- db.sql yalnız admin_user, signup və sliders cədvəllərini daşıyır.
- PDO prepared statement və password hash istifadə olunur, amma CSRF, role
  authorization, vahid validasiya, rate limiting və təhlükəsiz error handling yoxdur.
- Parol reset endpoint-i linki ekrana çıxarır; e-poçt, token expiry/hash və
  real reset tam deyil.
